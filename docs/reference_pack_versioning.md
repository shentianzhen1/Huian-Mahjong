# 素材包版本规则

后续素材包更新必须定版本号，用于核对手机、电脑和安装包是否使用同一份素材。

- 版本格式：`YYYY.MM.DD.N`，日期按北京时间，同一天的第 N 次素材发布从 1 开始递增。
- 当前内置参考素材版本：`2026.10.25.5`，共 13 张牌面（10 张普通牌、3 张开金显示参考）。
- 图片新增、删除、替换，或识别标签、清单、来源信息修正，都发布新版本；不得用旧版本号覆盖已发布内容。
- 仅说明文档、程序或打包方式变化，素材内容未变时保留原素材版本；程序版本与素材版本分别记录。
- 发布时同步更新 `bundle.json` 的版本及文件 SHA256、`bundled_references.py` 的 `REFERENCE_VERSION`，并记录本次变更和素材数量。
- 同一版本的 GitHub 素材、单独分发的素材包和安装包必须使用相同文件与校验值。独立压缩包命名为 `HuianMahjong-reference-pack-<版本号>.zip`。
- 安装包继续在 `BUILD_INFO` 中记录 `reference_pack_version` 与 `reference_pack_count`；程序素材状态显示版本、数量和校验结果。跨设备核对时同时看程序版本和素材版本，不能只比较文件名或下载日期。
- 更新只做素材校验及受影响功能的相关测试，不因素材版本管理增加无关的全量测试或人工审批。
