# AI Baseline V0.1

`BaselineAgent` 只从 Rules 给出的合法动作中选择，返回 `AgentDecision(action, reason)`：

1. 有HU则胡。
2. 需要弃牌时依次保留金牌、对子、同花色相邻或隔一张的搭子，优先打孤张；同分按牌编码稳定选择。
3. 响应时优先PASS保留当前手牌，不主动吃碰；强制摸牌时执行DRAW。

这是一套可解释启发式，尚无EV、危险度或特殊胡策略，不能声称优于真实玩家。
`PlayerObservation` 包含自己的手牌、公有牌河/花/副露、金牌、阶段、庄位和剩余牌墙数；不暴露对手手牌与牌墙顺序。
观察内的牌区使用不可变元组，决策理由写入Simulator日志，不改变动作元数据。

RandomAgent在 `workspace.simulator` 保留兼容入口；它的 `choose_decision()` 同样提供理由。
批量对战和运行命令见 [Simulator说明](../simulator/README.md)。


## EfficiencyAgent V0.2（实验）

`EfficiencyAgent` 暂不替换稳定的 `BaselineAgent`。它保持“HU优先、可选吃碰先PASS、强制动作照做”，只替换弃牌排序：

- 先评估弃牌后的整体成组结构；
- 再按公开牌河/副露扣除可见牌，计算下一摸对手牌结构的加权改良潜力；
- 绝不读取对手暗牌、牌墙顺序或保留牌；
- 决策日志记录 shape / weighted_gain / live_improving / types，便于A/B回归。

这是轻量一层牌效率启发式，不是完整向听数、危险度或Monte Carlo。只有在配对固定seed评估稳定优于旧Baseline后，才考虑升为默认基线。


### V0.2 A/B结果

固定20个match seed、正反换座，共40场8局全部完成。结果：EfficiencyAgent 6胜，BaselineAgent 33胜，1平；平均最终分 Efficiency=925.125、Baseline=1074.875，平均分差 Efficiency-Baseline=-149.75。

结论：V0.2没有通过晋级门槛，**不得替换BaselineAgent**。这说明“手工结构分+一摸改良潜力”会产生系统性错误弃牌。下一版优先做可验证的16/17张惠安牌型向听/有效牌，再考虑公开信息危险度和Monte Carlo/EV。


## ShantenAgent V0.3（保留对照基线）

`ShantenAgent` 使用惠安16/17张普通胡向听/有效牌引擎来排序弃牌。它保持：

- 合法HU优先；
- 可选吃碰先PASS；
- 不读取对手暗牌或牌墙顺序；
- 只把自己手牌、公开牌河、公开副露用于有效牌剩余张数。

弃牌先比较普通胡向听数，再比较公开信息下的有效牌剩余张数和有效牌种类。特殊胡继续由特殊状态机处理，不混入普通向听层。

### V0.3 对 BaselineAgent 的标准基线

2026-09-19 使用新的 `run_paired_real_matches()` 统一整场评估口径，固定20个match seed、正反换座，共40场8局，20/20 pair、40/40 match全部完成：

- ShantenAgent：38胜
- BaselineAgent：2胜
- 平局：0
- 平均最终分：1150.75 vs 849.25
- 平均分差：+301.5
- 点炮次数：12 vs 43
- 平均点炮/场：0.300 vs 1.075
- 320个单局中的胡牌来源：自摸265、点炮胡55
- UNKNOWN：0

此前旧代码快照曾得到37胜/3负、平均分差+228.25；该记录保留为历史。V0.3现在不再是默认前沿，但继续作为明确的对照/消融基线：任何后续策略都应同时保留与V0.3的可解释比较，防止风险层掩盖基础牌效回退。

## DangerAwareShantenAgent V0.4（实验，未晋级）

`DangerAwareShantenAgent` 在 V0.3 的最小向听层内加入公开实体牌暴露风险：

- `risk_units = 4 - 自己暗手同牌数 - 全部公开同牌数`；
- 这不是放铳概率，也不把对手曾打过的牌当成绝对安全牌；
- 向听数仍是硬约束，不允许为了安全退一档向听；
- `danger_weight=0` 必须复现 V0.3 的牌效优先级。

2026-09-19 做了固定牌墙+换座实验。pilot（seed 20–29，共20场/权重）中，0.25/0.5 权重均为7胜13负，平均分差-65.7；0.75/1.0为7胜13负，平均分差-73.3。随后对pilot中最好的0.25权重用新seed 100–119确认40场，结果22胜18负、平均分差+17.9。

两段独立seed合并看0.25权重共60场：29胜31负，Danger平均终分约995.02，V0.3约1004.98，平均差约-9.97。因此 **V0.4不晋级，不替换ShantenAgent V0.3**。结论是“单独使用同牌未见张数”信号对不同seed区间不稳定；该指标只保留为未来EV/对手模型的一个可审计特征。


## MatchAwareShantenAgent V0.5（实验，未晋级）

V0.5 只在固定8局比赛的**最后3局且当前玩家领先**时启用V0.4的0.25公开暴露风险权重；其余时点必须退化为V0.3。向听数始终是硬约束。

为了避免单一seed误导，使用两个互不重叠的20-seed区间，各做正反换座40场：

- seed 20–39：V0.5 19胜 / V0.3 21胜；平均分差 -3.2；点炮21 vs 21。
- seed 100–119：V0.5 20胜 / V0.3 20胜；平均分差 -0.5；点炮24 vs 24。
- 合并80场：V0.5约39胜41负，平均分差约 -1.85；点炮45 vs 45。

因此 **V0.5不晋级**。这说明把V0.4的“未见张数”风险代理仅放到末局领先场景，也没有观察到点炮降低或最终分收益。

## 普通点炮蒙特卡洛模型（研究基础设施）

新增 `workspace.ai.opponent.estimate_ordinary_deal_in_probabilities()`，但**尚未接管AI决策**。

它只使用玩家真实可见/可推导的信息：
- 自己暗手；
- 双方公开牌河与副露；
- 当前金牌种类；
- 对手公开副露数（用于推导普通结构下剩余暗手张数）。

算法从实体未见牌池中抽样可能的对手暗手，同一批抽样同时评估多个候选弃牌，再按现行单金/双金点炮限制判断“这张牌是否会让该抽样暗手普通点炮胡”。它不会读取真实对手暗手或未来牌墙，也不把对手曾打过的牌当成绝对安全牌。

该模型已经完成100局被动校准并被**明确淘汰**：2809次实际弃牌中有15次真实点炮，AUC=0.4993；实际点炮样本平均预测值为0%，Brier=0.0053455，甚至差于“始终输出基础点炮率”的常数模型0.0053115。根因是“均匀随机未见暗手”几乎不会生成经过多轮摸打塑形后的听牌手。因此该模型不得接入V0.6，也不得再把输出称为可用放铳概率。

## Tenpai-Conditioned Wait Risk（第二代研究模型）

第二代不再假装估计绝对点炮概率，而明确输出**听牌条件下的相对等待风险分**：先在公开实体牌约束下生成普通听牌模板，再比较某候选弃牌能补成这些模板胡牌的比例。它不估计“对手当前到底有多大概率已经听牌”，因此 `risk_score` 只能用于候选之间排序，不能显示成“放铳概率”。

第一批seed 0–99、100局、16个听牌模板/弃牌的被动校准：
- 100/100局完成，2809次弃牌，15次真实点炮；
- AUC=0.5628；
- 真实点炮样本平均风险分0.150，非点炮0.1285；
- 风险分0的397次弃牌中0次点炮；
- 0.0625档实际点炮约0.44%，0.10–0.25档约0.70%；
- 16模板平均需要约97.8次生成尝试；整批约33秒。

这说明它比均匀模型有弱但真实的排序信号，但风险分仍不是绝对点炮概率。后续独立seed验证允许它进入一个极窄的实验边界：只在V0.3的向听、有效牌总张数、有效牌种类数三项完全相同时，用相对风险替代最终固定牌序tie-break。


## TenpaiRiskTieBreakAgent V0.6（当前AI前沿）

`CurrentAgent` 现在正式指向 `TenpaiRiskTieBreakAgent`。V0.6不做广义“防守换牌效”，而是严格继承V0.3的前三层进攻排序：

1. 普通向听数；
2. 公开剩余有效牌总张数；
3. 有效牌种类数。

只有三项完全相同，才使用 Tenpai-Conditioned Wait Risk 选择相对风险更低的弃牌；若候选中含金牌，或风险模板生成失败，则回退V0.3的固定牌序选择。风险分只表示候选之间的相对排序，不能展示成“放铳概率”。

晋级前还修正了A/B随机性口径：随机seed必须跟Agent身份走，而不是跟座位走。该契约已有单测，避免换座时给V0.6换一套蒙特卡洛随机流。

最终晋级证据使用10个互不重叠seed区间，共 **300个seed pair / 600场完整8局**：

- V0.6：322胜；
- V0.3：275胜；
- 平局：3；
- 平均配对最终分差：**+18.9633**；
- 配对分差样本SD：146.4750；
- 标准误：8.4567；
- 约95%区间：**+2.3881 ～ +35.5385**；
- 点炮：V0.6 319次，V0.3 350次。

主判据是最终8局分差及其跨seed稳定性，点炮只作辅助诊断。完整归档见 `references/ai/2026-09-19/v06_promotion.md`。

下一阶段从V0.6继续做V0.7+：把当前庄底、赢家番、胡法倍率、比分和剩余局数引入可审计EV。新策略必须直接击败 `CurrentAgent`，不得只和V0.3比较，也不得用UNKNOWN特殊胡的猜测倍率训练。


## V0.7 / V0.8 实验结论

当前前沿仍是 `CurrentAgent = TenpaiRiskTieBreakAgent V0.6`。以下实验均保留代码/证据用于复现，但未晋级：

- V0.7a：在V0.6 exact-offense-tie内优先最小化tenpai-conditioned loss index；100 pair未显示稳定收益。
- V0.7b：保留V0.6 risk优先、只在risk同分时比较loss severity；首轮正向但独立确认未复现，合并200 pair的95%区间跨0。
- 64模板 vs 32模板：只增加采样量，不改变策略；100 pair无稳定收益，说明问题不是简单“模板数太少”。
- V0.8：在V0.3三项当前牌效完全相同时加入确定性的下一摸/下一弃二阶普通牌效，再回退V0.6风险。首轮100 pair平均分差+26.67、95%CI +3.05～+50.29；独立100 pair平均-5.25、95%CI -37.58～+27.08；合并200 pair平均+10.71、95%CI -9.38～+30.80，因此不晋级。

下一步不是继续盲调权重，而是在V0.6真实轨迹上做shadow decision diagnostics：统计V0.8到底在多少弃牌点改变选择、集中在哪个向听层、是二阶直接决胜还是仍回到风险，再据证据定义下一版。

算法/架构设计不受用户当前电脑型号限制。计算成本、延迟、内存/显存继续测量，但只作为工程指标；是否晋级仍以策略强度、准确率、稳定性和可复现证据为主。
