泉州麻将助手 V0.4

本版先使用苹果手机镜像测试，并优先开发二人麻将。暂时不使用采集卡。

安装

  1. 完整解压 ZIP 到英文路径，例如 D:\MahjongAssistant\。
  2. 双击 INSTALL_AND_RUN.bat。
  3. 程序会自动创建独立 Python 环境并安装 OpenCV、NumPy、Pillow、mss、pywin32。
如果现有 Python 3.14 安装 OpenCV/NumPy 失败，建议额外安装 Python 3.12 64-bit。无需卸载 3.14。

测试步骤

  1. 先把 iPhone 麻将画面镜像到 Windows。
  2. 点击 Select mirror window，选择镜像窗口。
  3. 点击 Calibrate hand ROI，框住你底部的全部手牌。
  4. 点击 Calibrate draw ROI，框住右侧单独摸牌区域。
  5. 点击 Start monitoring。

绿色框代表当前检测到的麻将牌候选。识别异常时点击 Save snapshot，或者查看 data\bad_frames\。

V0.4 重点是“看得稳、分得开”。V0.5 才会继续加入完整牌面识别和基础 Top 3 出牌建议。
