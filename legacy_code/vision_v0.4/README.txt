Quanzhou Mahjong Assistant V0.4

Focus of this build:
- Windows 11
- iPhone mirror window first
- Two-player Mahjong first
- Manual hand/draw ROI calibration
- OpenCV tile-candidate segmentation
- Stable-frame gating
- Automatic saving of bad frames

This build does NOT yet contain the final tile classifier or strong EV AI.
Its goal is to make the visual input stable before V0.5.

Quick start:
1. Extract the ZIP to an English path, for example D:\MahjongAssistant\
2. Double-click INSTALL_AND_RUN.bat
3. Select your iPhone mirror window
4. Calibrate HAND ROI
5. Calibrate DRAW ROI
6. Start monitoring

If Python 3.14 causes dependency problems:
Install Python 3.12 64-bit. You can keep Python 3.14 installed.
