## 配置解释和边界

该页面直接支持“单金不平胡是房间可选项”。按选项文字映射：
勾选对应 `single_gold_can_pinghu=False`；未勾选对应 `True`。
本图当前未勾选，因此若保持选项创建房间，应为 `True`。
这是设置文字的解释，仍需实际房间/对局核验；不能将截图选择当作已生效的对局配置。
用户此前反馈通常设置为不可以平胡，与本图的未勾选状态并不冲突。
保留项目默认 False，不从单张设置截图推断产品默认值或所有房间设置。

本图未展示底分、倍数链、抢杠、游金过程或结算，因此对应 UNKNOWN 不变。
托管选项只记录 UI 事实，不推断其计时触发点或自动动作策略。
