## 结论与边界

四张实际结算页（另有此前归档的自摸 +38）一致支持已观察到的普通平胡与自摸的二人结算：
`(当前庄家底 + 赢家手牌番) × 胡牌倍率`，赢家加、另一家减。

证据尚未覆盖抢金、三金倒、游金、点杠、流局时杠分或所有杠种，因此不能将该式扩展为这些类型的最终规则。
