# Vision V0.1 — 8局真实录像首轮基线

日期：2026-09-19（Asia/Shanghai）

## 数据来源

- 目标房完整8局回放，共8段：3/4/5/9/10/11/12/13.mp4。
- 两种真实录像分辨率：1046×480、960×448。
- 自动抽帧与近重复筛选后保留379个关键帧，生成1137个 hand/draw/gold ROI 裁剪。
- 首批人工审核标签168个，来自8个独立录像 session，覆盖34/42个牌类。
- 原始视频、关键帧和ROI图片不提交公开仓库；本报告只记录匿名化统计结果。

## 严格评测口径

所有真实基线采用：

1. `source_session > source_frame > image` 分组；同一录像的相邻帧绝不能跨训练/测试。
2. 牌面准确率采用 `same_region + leave-session-out`；hand / draw 不互相借模板。
3. 空槽先做牌面存在检测；没有可信亮色麻将牌主体的槽位不生成任意 tile_id。
4. `gold_region` 按当前回放事实改为 `marker`：左上角是黄色牌背/金状态标记，不显示具体金牌牌面，因此不进入 tile_id 准确率。
5. 所有结果继续 `safe_for_executor=false`。

## Gold 观测边界修正

8局回放从局内动作开始，左上角始终只有黄色牌背标记。它能证明金状态UI存在，但不能告诉 Vision “哪张牌是金”。

因此当前设计改为：

```text
实时开金/翻金事件
  -> 直接识别可见牌面
  -> 写入并记忆 gold_id
  -> 对局中 gold marker 只检查状态标记是否存在
```

这8段回放没有录到真正翻金牌面，因此不能用于评估 gold_id 识别准确率；任何从黄色牌背硬猜 tile_id 的数字都无效。

## 牌面主体归一化

draw ROI 常带较多深色桌面/UI边缘。新增预处理：

- 灰度阈值找亮色区域；
- 3×3闭运算；
- 取最大可信亮色连通块；
- 只有面积和尺寸达到牌面门槛才认为槽位有牌；
- 裁到牌面主体后统一缩放到48×72，再做模板特征；
- 空槽直接跳过。

该变化不增加训练数据，也不改 leave-session-out 口径。

## 归一化后正式 strict baseline

| 区域 | 可评估 | 精确牌面准确率 |
| --- | ---: | ---: |
| hand_region | 126 | **95.24%** |
| draw_region | 25 | **100.00%** |
| 合计 | 151 | **96.03%** |

- 可评估覆盖率：151 / 168 = 89.88%
- 类别准确率：**98.68%**
- 置信阈值0.80：127 / 151 被接受（84.11%覆盖），接受样本精确准确率 **98.43%**
- hand：107 / 126 被接受，接受样本准确率 **98.13%**
- draw：20 / 25 被接受，接受样本准确率 **100%**
- 置信阈值0.90时，保留样本的精确准确率约98%。

剩余已观察错误集中在 hand_region，主要包括 P2↔S2、P4↔P2、M8→M2、S4→S3 等相似牌面。

## Presence-aware 连续帧稳定性

旧稳定性统计会对空 draw 槽也强行生成预测，因此不能作为门槛。加入牌面存在检测后，在8段视频相同的9.5s–10.4s固定窗口复核：

- hand：127 / 128 稳定 = **99.22%**
- draw：该固定窗口中只有2段视频真正持续出现摸牌，2 / 2稳定 = **100%**；样本量太小，不能单独作为最终门槛。
- tile 槽合计：129 / 130稳定 = **99.23%**
- gold marker：8 / 8视频、每段10 / 10帧均检测到标记，marker persistence = **100%**；这不是 gold_id 准确率。

下一步还需要从完整录像中自动挑更多“draw持续可见且画面未发生真实出牌变化”的序列，扩大时间稳定性样本。

## 当前覆盖缺口

- 尚未覆盖：F1、F3、F4、F5、F6、F8、S7、S9。
- F2、F7 当前只有单一独立 session。
- draw 静态严格基线已明显改善，但还要扩大连续可见序列的时间稳定性样本。
- gold_id 必须新增**真正从开金前开始录制的实时画面**；现有回放只能验证 marker。
- 仍需要不同录屏批次、窗口缩放/移动/遮挡作为外部验证集。

## 下一步门槛

1. 自动发现更多稳定 draw 可见序列，扩大 presence-aware temporal stability。
2. 补齐缺失牌类和跨 session 重复。

5. 只有“跨session牌面准确率 + presence-aware多帧稳定性 + gold reveal可复现 + 后处理约束”共同达标后，才讨论 Executor。
