## 修正后的正式 hand + draw 静态基线

在同一模板算法、同一严格留组口径下，修正错标签后：

| 区域 | 可评估 | 正确 | 精确牌面准确率 |

| gold_region | 0 | — | 跨session泛化暂不可评估 |
| hand+draw合计 | 149 | 147 | **98.66%** |

- 可评估覆盖率：149 / 168 = **88.69%**
- 万/筒/条/字/花大类准确率：**100%**
- 置信阈值 ≥0.80：127 / 149 被接受（**85.23%覆盖**）
- 这127个高置信样本：**127 / 127 = 100%**
- 当前剩余2个严格错误都在 hand_region：
  - S4 → S3，置信约0.736
  - M8 → M2，置信约0.755
- 两个错误都低于0.80运行阈值，因此当前“高置信通过 / 低置信拒绝”策略能把它们挡住。

这次结果也否定了“必须立刻换模型”的冲动。对同一修正后标签集做实验性线性 SVM 留组对照：

因此主分类器继续保留当前模板方案；SVM不晋级。

## Gold V0.1

用户确认真实视觉结构是：

```text
普通底层牌面
+ 黄色/金色皮肤
+ 右上角“金”角标
```

所以 Gold V0.1 不创建一套重复牌类，而是输出普通 `tile_id` + `is_gold=true`。

8局人工真值：

- 3.mp4 = S8（8条）
- 4.mp4 = M8（8万）
- 5.mp4 = P5（5筒）
- 9.mp4 = M3（3万）
- 10.mp4 = P2（2筒）
- 11.mp4 = M7（7万）
- 12.mp4 = B（白板）
- 13.mp4 = P4（4筒）

方法：
- SIFT局部特征识别底层牌面，并屏蔽右上角“金”角标；
- 若判为筒子族，再用Hough圆检测统计点数消歧。

单张种子实验：
- 仅局部特征：6/8
- 加筒子圆点二阶段：8/8

进一步从8段录像各采约25个时点做**同批录像多帧测试**：
- 检测到gold的帧：196
- 正确：193
- 帧级准确率：**98.47%**
- 8/8局的多数票 gold_id 全部正确
- 筒子金 P2/P4/P5 的73个抽样帧中，圆点数72/73正确 = **98.63%**

逐局多帧：
- S8：23/23
- M8：24/25
- P5：25/25
- M3：25/25
- P2：24/25
- M7：25/25

注意：98.47%是**当前同一批8局的时间稳定/帧级结果**，不是新录像上的跨批次泛化准确率。严格gold跨session同类泛化仍需同一种gold在独立录像中重复，或新增外部录像批次。

## PublicState V0.1

两侧玩家面板确认都是“头像 + 头像下方当前分数”。头像/昵称不做身份识别，只作为定位锚点。

已新增 `public_state.py`，先把“像素读取”和“是否信任状态”分离。当前融合层约束：

- 双方分数必须是整数并满足 **A + B = 2000**
- 多帧短窗口多数票
- 可与引擎 `MatchScoreState` 当前分数交叉校验
- 同一局内分数不能突然变化
- 第几局只能1..8，不能倒退或一次跳多局
- 同一局内剩余牌数不能增加
- 异常帧只产生 issue，不覆盖可信状态
- 永远 `safe_for_executor=false`

真实8局在约10秒稳定时点已建立 PublicState 真值夹具：
`references/vision/2026-09-19/match_evidence_001_public_state_seed.json`

其中包括每局：
- 双方当前分数
- 第几局/8
- 剩余牌数
- gold_id
- 分辨率

例如第8局稳定帧：
- top-right = 1077
- bottom-left = 923
- 剩105张
- 第8/8局
- gold=P4
- 1077+923=2000

PublicState约束层已经有回归测试；下一步才是接具体数字识别器，数字模型可以替换，而约束层不需要重做。
