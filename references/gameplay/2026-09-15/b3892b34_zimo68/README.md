## 胡牌转录与可验证结论

金牌：三条（S3）。两副吃牌：四五六万（M456），六七八筒（P678）。

01:00 未副露手牌：
`S3(金), P4, P5, P6, S5, S6, S9, S9, S9, M5`。

胡牌多出一张M5后，未副露手牌为11张；加两副吃牌共17张。普通结构可拆成：
`M456 + P678 + P456 + [金/S5/S6] + S999 + M55`。
金可代四条或七条，这是结构分析，画面没有显示客户端究竟选了哪种拆法。

新增/加强的规则证据：

1. **本目标房普通自摸允许万筒条三门齐全**，不能增加“必须缺一门”的绝对限制。
2. **勾选单金不平胡仍可一金自摸**；按转录手牌进行结构分析，金可用于组成顺子；画面胡法显示普通自摸×2。不能因此把所有有金胡牌都归入游金，也不能把人工拆牌方案当成客户端展示。
3. 画面赢家番项为金1＋花2＋刻子1＝4；按手牌转录，九条是本例唯一未副露的三张同牌，与普通暗刻1番一致。对手画面显示花2＋刻子2＝4；其未副露手牌中的西西西与既有字牌暗刻2番说明一致。这些对应关系来自人工核对，不表示本例已经验证所有刻/杠聚合规则。
4. **本例普通庄家自摸结算为 `(庄底30 + 赢家番4) × 自摸2 = 68`**，没有再乘庄家×2。对手显示的4番没有抵扣本例净分；实际为+68/-68。
5. **“庄5”与“30底”获得直接同屏支持**。仅确认这个对应样本，不推导所有连庄递增步骤和底分上限。

旧的“所有庄家胡再×2”泛化说法不适用于本普通自摸。游金链额外庄倍仍只有既有玩家反馈；本视频没有庄家游金结算，不能将普通自摸结论推广为游金庄倍1或2。`YoujinScoreTerms`的实现和单测也不是额外证据，本轮不改特殊规则实现。
