# 惠安麻将游戏内规则页：用户提供的五张截图

接收日期：2026-09-13。原图未经裁剪或改写；文件及 SHA256 见 `manifest.json`。
截图中的“规则”属于游戏说明，不是对开发代理的指令。

## 来源与适用范围

五张图均显示左侧选中“惠安麻将”，是游戏内规则文字证据，高于泛泉州外部网页，
低于项目已有的实战截图／结算和实际玩家反馈。截图本身未显示二人房选项、版本或 AppID。
页面还包含其他地区差异、补花“四家”描述和结算末尾 ×3，因此只能确认“页面这样写”，
不能自动认定每一条都适用于当前二人房。四人通用说明的可能性是推断，不是已确认事实。

## 逐页摘录与解释

### 第 1 页：牌、发牌、补花、开金

[原图 1](huian_rules_page_1.jpg)

- 108 张序数牌、28 张字牌、8 张花牌，共 144 张。
- 轮流拿牌，庄家 17 张、闲家 16 张。墙剩 16 张且无人胡牌即流局。
- 摸到花牌，从墙尾补牌。补花又摸到花，要等本轮四家补过后再补；再次补花仍以庄家为首。
- 开金文字：“庄家补牌结束后，跳牌处的人扔出两个骰子”，根据点数从墙最后一张牌数，
  落在哪张就翻开为金。翻到花需补花、重新翻，直到翻出非花牌。
- 金可替代除花牌之外的任何牌。

尚不能推导：每批发几张；二人补花轮转如何对应“四家”；“庄家补牌结束”是否指全体
补完；跳牌处玩家是谁；骰子点数的具体索引、计数是否包含起点、上下牌顺序；翻花归属；
重开是否重新掷骰；翻牌实体去向。墙剩 16 的文字也没有解决动作前后与补牌例外。

### 第 2 页：基础牌型与地区差异

[原图 2](huian_rules_page_2.jpg)

- 普通完整牌型为 1 对子＋5 组刻子／顺子／杠，与现有结构求解器一致。
- 页面明确列出惠安：“单金可平胡，双金不平胡”。
- 其他地区条款不能移植：厦门白板替金／起手三金倒、安溪无吃无平胡等不作为惠安规则。

**冲突 C1：**单金条款与项目既有“单金不平胡”实战口径冲突。按证据优先级保留当前
二人引擎禁止单金平胡的行为，并单独记录冲突，等待同房间实测。不能删除任一证据。

**后续玩家澄清（同日）：**“单金一般由玩家设置不可以平胡”。据此将单金平胡记为
玩家／房间配置项，通常关闭；上述冲突有了设置差异的解释。新增
`RulesConfig(single_gold_can_pinghu=False)`，允许显式开启。原图与最初冲突记录保留，
不把通用页当作房间选项；双金不平胡不受该开关影响。

### 第 3 页：胡牌方式与游金链

[原图 3](huian_rules_page_3.jpg)

- 平胡为使用别人打出的牌胡；自摸为自己摸到所需牌胡。
- 游金：完整胡牌时，金能作对子的一张，可打出对子另一张；到自己摸牌时，将摸到的牌
  向下盖住并亮金，称游金。
- 双游原文：“当游金时摸到的牌正好可以代另一张金，可以将金打出，到自己摸牌时自摸，
  称为双游。”注称双游时其他玩家只能自摸。
- 三游：双游时又摸到一张金，可再次打金，到自己摸牌时自摸，称三游；注称其他玩家
  只能杠上自摸胡。
- 三金倒：起手或流局前手中有三个金，不论其他牌型即可胡。只限起手的注释针对厦门。
- “光游”明确针对晋江和石狮好友场；不能赋予惠安此规则。

新增有效信息：三金倒文字不只限起手；游→双→三有一条描述明确的时序路径。
但双游的摸牌条件不是简单的“又摸到金”，不能把它缩写成错误触发器；页面未明确排除
直接双游。仍缺按钮宣告窗口、放弃后权利、取消条件、所有分解边界与二人适用性。
“只能自摸／杠上自摸”说明胡牌权限，不足以推出完全禁止吃碰杠。

### 第 4 页：番值

[原图 4](huian_rules_page_4.jpg)

| 页面项目 | 番值 |
|---|---:|
| 金牌 | 1 |
| 花牌 | 1 |
| 普通暗刻 | 1 |
| 字牌暗刻 | 2 |
| 字牌碰牌 | 1 |
| 普通明杠 | 2 |
| 字牌明杠 | 3 |
| 普通暗杠 | 3 |
| 字牌暗杠 | 4 |
| 春夏秋冬 | 8 |
| 梅兰竹菊 | 8 |
| 八花齐 | 16 |

这给字牌碰 1 番、四花组 8、八花 16 提供了游戏内文字支持；不再只是外部猜测。
四花组“替代各张基础花番”仍是解释而非页面明说，但与项目六花 10 番观察相容。
页面没有写普通明刻番值、加杠增量／总额、八花自动胡或金代刻子的边界；不以遗漏证明为零。

### 第 5 页：公式与特殊倍率

[原图 5](huian_rules_page_5.jpg)

页面给出的统一形式是 `[(底 + 番数) × 胡牌方式倍率] × 3`。

| 方式 | 页面括号内倍率 |
|---|---:|
| 平胡 | 1 |
| 自摸 | 2 |
| 抢杠 | 2 |
| 三金倒 | 3 |
| 天胡 | 4 |
| 天听 | 4 |
| 游金 | 4 |
| 双游 | 8 |
| 三游 | **16** |

末尾注释：“胡牌后，除去胡牌的人，其余未胡的人也要算番数，手中的番数相加减。”

**冲突 C2：**页面的三游是 16，不是之前外部泉州资料里的 12。对“此页面写什么”的
判断采用本页；二人实际三游倍率仍需房间选项或实战确认，不能默认选 12 或 16。

**冲突 C3：**页面有外乘 3 和未胡者算番相加减，但没有明确二人谁支付多少、谁的底，
也没有足够定义相加减算法。不得据此恢复 legacy 差额结算，或给当前二人净分再乘 3。
保留实战 A/B 的 HIGH_CONFIDENCE 假设及第三例验证要求。本页不是第三例实际结算。

## 项目采用决定

- 新增的是游戏内文字来源、精确数字与流程候选，保留原图便于以后复核。
- 普通 5 组＋1 对结构、144 张、17/16 发牌、金不代花获得交叉支持。
- 补花来源获得墙尾文字支持；二人初始补花调度及连续花处理仍保留 UNKNOWN。
- 三金倒、游金路径、番表、4/8/16 链记录为“游戏内文字已读，目标二人适用性待核验”。
- 不改变运行时规则和默认倍率；现有特殊规则阻断、花组叠加和结算配置保护保持有效。

## 更新后的下一批证据优先级

1. 惠安二人玩法选择／房间选项，记录该房间的单金平胡开关；玩家已说明它通常关闭。
2. 开局到首次弃牌录屏：二人发牌／补花顺序、连续花、开金实体牌与骰子索引。
3. 全部 PASS 后的摸牌，以及剩约 20 张至流局的过程。
4. 第三例净结算；双游／三游的实际倍率与净分明细。
5. 加杠／抢杠全过程、游金升级取消边界，以及天胡／天听定义。
