# tiles_v0_1 dataset

此目录保存本地 Recorder V0.2 素材的关键帧、ROI 裁剪、人工牌面标签和可审计元数据。提交示例时不要加入真实账号、房间号或不应公开的个人信息。

原始关键帧、ROI 图片和自动生成的帧元数据默认由 `.gitignore` 排除，避免误提交大量真实录像画面。人工审核后的 `labels/tiles.jsonl` 与 ROI profile 可以按需加入版本控制。

目录与处理步骤见 [`workspace/vision/tiles_v0_1/README.md`](../../workspace/vision/tiles_v0_1/README.md)。
